## Fields kept

- **FLR**: flrID, beginTime, peakTime, endTime, classType, sourceLocation, activeRegionNum, link
- **CME**: activityID, startTime, sourceLocation, activeRegionNum, link + most accurate analysis: speed, type, halfAngle, latitude, longitude
- **SEP**: sepID, eventTime, instruments, link · **GST**: gstID, startTime, allKpIndex, link · **IPS**: activityID, eventTime, location, link
- **WSAEnlilSimulations**: simulationID, modelCompletionTime, estimatedShockArrivalTime, isEarthGB, impactList (location, arrivalTime, isGlancingBlow), cmeInputs (cmeStartTime, speed, halfAngle, longitude), link
- **RadLab**: timestamp, absorbed_dose_rate (µGy/h) for instrument_id `MSL-RAD-Surface` → per-day time-weighted dose, mean and peak rate, and a thinned curve
