## Not SI-generated (for clarity)

- All 3D scenes, cutscene footage and the demo video: the real-time game itself, captured frame by frame (`web/scripts/capture.mjs`).
- Terrain: NASA Mars Reconnaissance Orbiter data. Rover model: NASA 3D Resources. Ground and rocks: Poly Haven scans (CC0).
- Sound effects and music: generated by code at run time (`web/src/audio.ts`).
- Read-aloud: the browser's built-in synthetic speech, switched off by default.
