# PlutonyX — Junior Astronaut Mission Trainer

**NASA Space Apps Challenge 2026 · Challenge: "Build a Junior Astronaut Mission Trainer" · Team PlutonyX**

> Keep your crew alive on Mars, where every choice costs something precious and the real Sun decides how hard it gets.

*Working title: PROJECT JEZERO. This README is a stub and will be completed before submission.*

Two editions of one game:

| Edition | Folder | Built with |
|---|---|---|
| **Web** (play in the browser, no download) | [`web/`](web/) | Three.js, TypeScript, Vite |
| **Desktop Ultra** (Windows download) | [`desktop/`](desktop/) | Unity |

Both read the same design and the same real NASA data from [`shared/`](shared/). Start with [`shared/GAME_BIBLE.md`](shared/GAME_BIBLE.md).

## Real NASA data in the game

- **DONKI** (NASA CCMC): solar flares, coronal mass ejections and NASA's predicted arrival times at Mars
- **RadLab** (NASA OSDR): radiation measured on the surface of Mars by the Curiosity rover
- **Mars Reconnaissance Orbiter CTX** elevation and imagery of Jezero Crater (USGS / NASA Mars 2020)
- **JPL** planetary orbit elements for the real Earth–Mars radio delay

Archived snapshots and their source URLs: [`shared/data/SOURCES.md`](shared/data/SOURCES.md).
