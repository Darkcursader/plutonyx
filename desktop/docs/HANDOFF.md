```

python3 tools/fetch_textures.py && tools/.venv/bin/python tools/terrain/prepare_layers.py   # after a fresh clone (CC0 textures are not in git)
```

## Known bugs / gotchas
- `VolumeProfile.Add<T>()` in editor code does not persist unless each component is `AssetDatabase.AddObjectToAsset`'d (done in WorldBuilder).
- A camera shot's LookAt child must be created **after** the parent is rotated/scaled (fixed in OutpostBuilder.Shot).
- Ending a sol with exactly 0 power counts as a blackout (`whenPowerAtOrBelow: 0`); two in a row = evac. Keep ≥ 1 point.
- DONKI: use `https://ccmc.gsfc.nasa.gov/DONKI/WS/get/<TYPE>`; `api.nasa.gov/DONKI/FLR` returned 404; `kauai.` host is dead.
- The project path contains a space: always quote paths. Internet here is slow and drops; downloads must be resumable.
